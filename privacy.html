Privacy Policy

Minecraft Backups is a personal server backup application.

Google Drive Access

The application uses Google Drive API access to upload, read, verify and manage backup files it creates.

Data Usage

Backup data is used for Minecraft server recovery. It is not sold or used for advertising.

Data Storage

Backups may contain Minecraft world data, player information and server configuration. Files are stored on the server and the owner's Google Drive.

Revoking Access

The account owner can revoke application access through their Google Account security settings.
